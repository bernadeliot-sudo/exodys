# macOS 功能对齐清单

本清单追踪可运行的用户流程，不比较性能或外观，也不表示文件格式互通。参考 [Karing v1.2.26.2934](https://github.com/KaringX/karing/releases/tag/v1.2.26.2934) 和 [项目说明](https://github.com/KaringX/karing#readme)。范围限 macOS，不包含移动端。以下是第一批已核对的功能，不是上游所有设置的完整枚举。

| 用户流程 | Exodys 本地实现 | 尚缺／验收条件 |
| --- | --- | --- |
| 导入、更新订阅 | URL、文件、粘贴；Clash YAML 和 sing-box JSON 中的独立节点；链接列表；Shadowsocks SIP008 v1。手动刷新失败保留上次内容 | 不等于完整 Clash/Meta 配置支持；SIP008 插件节点跳过。仍需验证策略组、规则引用和定时更新 |
| 选节点、连接和测试 | 稳定节点选择、连接中切换、经本地代理发送单次测试请求 | 跨订阅节点组、自动选节点和故障切换尚未实现；需用可控上游验证切换与恢复 |
| 按目标分流 | 断开时编辑全局有序规则；域名、后缀、关键词及 IPv4/IPv6 CIDR；直连、所选节点或拒绝 | 尚无按组选择出口、GeoIP/GeoSite、远程规则集或从订阅自动迁移规则 |
| 接管系统流量 | 回环 HTTP/SOCKS5；可选 macOS 系统 HTTP/HTTPS 代理，连接时应用、断开或窗口进程退出时按原值恢复 | 只处理连接时的主网络服务；非 TUN。守护进程和配置合并有隔离测试，真实网络服务写入、应用实际流量及系统授权弹窗需在专用 Mac 验收 |
| 本地迁移与同步 | 版本化 JSON 导出和恢复本地端口及规则；恢复保留当前节点库 | 不含节点或订阅，不兼容 Karing ZIP；完整备份、WebDAV、iCloud 和局域网同步尚未实现 |

## 可重复验证

- 常规测试覆盖导入、更新、旧设置读取、非法规则不落盘、设置导出与恢复。
- `tests/proxy.rs` 使用真实 sing-box、临时端口和回环服务，区分直连、拒绝及未命中回退行为。
- `examples/native_smoke.rs` 在真实 AppKit 窗口中打开规则编辑器、写入并保存；另验证节点切换、连接、断开和资源释放。系统文件面板选取文件未自动化。
