# macOS 功能对齐清单

本清单追踪可运行的用户流程，不比较性能或外观，也不表示文件格式互通。参考 [Karing v1.2.26.2934](https://github.com/KaringX/karing/releases/tag/v1.2.26.2934) 和 [项目说明](https://github.com/KaringX/karing#readme)。范围限 macOS，不包含移动端。下表列出已核对的用户流程。

| 用户流程 | Exodys 本地实现 | 尚缺／验收条件 |
| --- | --- | --- |
| 导入、更新订阅 | URL、文件、粘贴；Clash YAML 和 sing-box JSON 独立节点；链接列表和 SIP008 v1；手动和可选定时更新，逐条订阅可设周期或仅手动刷新，失败保留上次内容 | Clash/Meta 支持独立节点和兼容规则；SIP008 插件节点跳过 |
| 选节点、连接和测试 | 手动选择及在线切换；默认跨配置自动组；最多八个独立策略组，各自使用手动出口或 URLTest；单次代理测试 | 尚无动态成员规则、连接期间切换策略组出口或实际自动出站节点显示 |
| 按目标分流 | 有序规则支持域名、CIDR、直连、代理、拒绝或 `GROUP:组名`；可从本地 Clash YAML 读取兼容规则到草稿；本地文件或 HTTPS 导入 sing-box `.srs`，支持 `RULE-SET`、`GEOIP` 和 `GEOSITE` 引用 | 已安装的规则集可单独启用 HTTPS 定时更新，下载失败保留原副本；尚无内置 Geo 数据或从订阅自动应用规则 |
| 接管系统流量 | 回环 HTTP/SOCKS5。可选 macOS 系统 HTTP/HTTPS 代理，接管连接时的主网络服务。TUN 按当前节点或自动组、引用的策略组、分流规则及规则集请求同版本配置 | TUN 需要管理员部署服务并批准实际使用的版本。特权服务注册、真实流量和路由恢复需在独立 macOS 环境验收。系统代理的真实授权弹窗和网络服务写入也需单独验收 |
| 备份与跨设备配置 | `.exodysbackup` 加密快照可完整恢复。共享文件夹支持按设备发布加密版本、合并独立改动以及提示处理重叠改动。设置 JSON 可单独转移端口和规则 | 自动同步限应用运行且代理断开时，重启后需重新解锁。验收使用两个独立本地配置库和模拟文件交付。专用云服务接入与 Karing ZIP 导入超出本版范围 |

## macOS TUN 的部署与验收

退出 Exodys 后，开发者可用 sing-box 1.14 或更新版本预检 TUN 配置。预检读取当前工作区的节点、策略组和分流规则，在一份引擎配置中构造双栈 TUN 入站与代理出站。配置要求检测物理网卡，并使用调用方指定的 DNS IP；带有网卡或源地址绑定的节点会被拒绝。下例使用文档专用地址，命令仅调用 `sing-box check`，不会连接该 DNS 服务器或启用 TUN。

```bash
cargo run --locked -- --check-tun-config 192.0.2.53
```

`--prepare-tun-config` 为当前连接生成可审核的配置。应用连接时重新计算配置编号，服务核对管理员批准的配置及 `.srs` 文件，随后启动同一个 sing-box 进程处理 TUN 和出站。应用断开后服务停止引擎。[配置准备、部署与验收](tun-macos.md)

## 可重复验证

- 常规测试覆盖导入、更新、旧设置读取、非法规则不落盘、设置导出与恢复。完整备份测试将合成订阅、认证节点和策略组转移到另一独立配置库，并覆盖错误口令、篡改和恢复提交失败。
- 规则集备份测试在目标配置库恢复二进制副本，使用真实 sing-box 确认恢复后的请求仍按规则匹配。
- `tests/sync.rs` 用两个独立配置库和临时文件夹，手动触发同步并模拟文件交付。覆盖离线改动合并、端口冲突、失效的冲突确认、父版本延迟到达、错误口令、重启后重新解锁及设备设置保留。
- `tests/proxy.rs` 使用真实 sing-box、临时端口和回环服务，区分直连、拒绝及未命中回退行为。
- `tests/tun.rs` 使用合成节点和实际 CLI 验证两种地址族的 DNS 配置、手动节点切换、自动组、命名策略组、分流及规则集更新。TUN 客户端与服务测试覆盖账户验证、请求格式、缺少批准、配置和规则集被修改、启动确认、停止确认及异常退出。真实 sing-box 回环测试验证服务能等待引擎启动并在断开时回收进程。
- `src/engine/tests.rs` 用真实 sing-box 编译合成 `.srs`，验证 GeoIP、GeoSite 和显式规则集引用，覆盖替换失败和 HTTPS 定时更新失败时保留原副本、更新失败后的退避，以及引用缺失时阻止连接。同文件的 URLTest 测试切断合成回环上游后，验证新请求改走另一成员。两项测试均使用回环上游。
- 独立策略组测试让不同目标走不同回环上游，并验证已用配置在连接期间不可删除。
- `examples/native_smoke.rs` 在真实 AppKit 窗口验证跨配置成员管理、独立策略组建组和选择出口、订阅周期编辑、规则编辑、规则集定时来源的保存与关闭及手动连接生命周期。同一驱动通过原生安全输入框解锁已记住的共享文件夹，手动触发同步，确认冲突后检查新版本写入，并验证暂停后可重新解锁。独立窗口操作还确认备份保存和恢复面板可以打开，安全口令框接受回车并校验长度。完整文件往返由隔离配置库的集成测试验证。
